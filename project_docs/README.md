## Project Docs Layout

- `deployment/`: deployment runbooks, env examples, and invocation helpers for the hosted-app and proxy setup
- `reference/`: onboarding notes, reports, and architecture reference material
- `agntcy/`: diagrams, slides, and archived discovery/identity notes

These files are kept for reading and handoff purposes only. The live hosted application and proxy runtime do not import anything from `project_docs/`.
Some archived notes and diagrams still mention older local-run files such as `main.py`; treat those as historical reference, not active runtime paths.
